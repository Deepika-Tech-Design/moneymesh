# MoneyMesh

MoneyMesh is a BIS-standards-aligned FinTech hackathon prototype covering 50 real-world financial problems.

## Run locally
1. Open this folder in VS Code.
2. Open `index.html`.
3. Use the Live Server extension, or double-click `index.html`.

## GitHub Pages
This project is static HTML/CSS/JavaScript and can be hosted directly using GitHub Pages.

## Important
- This is a hackathon prototype.
- It is designed with reference to relevant BIS standards and is not claimed to be BIS-certified.
- Demo data is stored in browser localStorage.
- No real bank transfer or live banking API is connected.
